# TP Patte d'oiseau — SYSMER 3A (SeaTech)

Modélisation cinématique d'une patte d'oiseau en Python à partir de données de capture de mouvement.

Réalisé en binôme : E. Cherif & Guivarch.

- `TP patte oiseau.ipynb` : notebook principal
- `model.py`, `myleg.py` : modèle de la patte
- `fich-from-data-scilab/` : données de positions des articulations
- `rapport/` : compte rendu (PDF)

## Utilisation
```bash
pip install numpy matplotlib pandas openpyxl jupyter
jupyter notebook "TP patte oiseau.ipynb"
```
